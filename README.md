# Perfume Finder — PWA

وب‌اپلیکیشن فارسی و راست‌چین برای کشف عطرها، برندها و رایحه‌های مشابه. آماده انتشار روی GitHub Pages.

## امکانات نسخه 2.0
- رابط کاربری واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- جست‌وجوی هوشمند در نام عطر، برند، کشور، خانواده، توضیحات و نت‌ها؛ پشتیبانی از تعدادی واژه انگلیسی رایج مانند oud / rose / vanilla / fresh
- اسلایدر طیف رایحه از خنک و تازه تا گرم و عمیق
- فیلتر کشور سازنده، برند، جنسیت، خانواده بویایی، نت، فصل و مرتب‌سازی
- صفحه جزئیات با نت‌های آغازین، میانی و پایه و توضیحات
- پیشنهاد رایحه مشابه بر اساس هم‌پوشانی نت‌ها، خانواده و برچسب‌ها
- پیشنهاد بین‌کشوری فرانسه ↔ امارات؛ در صفحه جزئیات، کشور مقصد پیشنهاد مشابه قابل انتخاب است
- علاقه‌مندی‌های ذخیره‌شده در حافظه محلی دستگاه
- PWA قابل نصب و کش آفلاین

## انتشار روی GitHub Pages
1. فایل‌های این پوشه را در ریشه مخزن GitHub قرار بده.
2. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن.
3. شاخه `main` و پوشه `/ (root)` را انتخاب و ذخیره کن.
4. پس از انتشار، آدرس GitHub Pages را با Chrome موبایل باز کن و از منوی مرورگر Install app / Add to Home Screen را بزن.

## داده‌ها و محدودیت مهم
فایل فعلی `data.json` شامل 16 رکورد نمونه است؛ این نسخه رابط کاربری و منطق پیشنهاد مشابه را آماده می‌کند، اما ادغام کامل دیتاست‌های بیرونی به معنی وجود داده کامل در این ZIP نیست. برای کاتالوگ جامع باید فایل‌های داده واقعی و مجاز در `sources/` قرار بگیرند و Pipeline اجرا شود. داده FragDB کامل مجوز تجاری دارد و نباید بدون مجوز بازنشر شود. فایل Scento باید با انتساب مجوز CC BY 4.0 استفاده شود. پروژه fragscrape ابزار استخراج است، نه دیتابیس آماده؛ رعایت شرایط سایت منبع ضروری است.

## فایل‌های اصلی
- `index.html` رابط کاربری
- `app.js` جست‌وجو، فیلترها، اسلایدر و الگوریتم مشابهت
- `data.json` کاتالوگ محلی
- `manifest.webmanifest` تنظیمات نصب PWA
- `sw.js` کش آفلاین و به‌روزرسانی نسخه
- `tools/` و `.github/workflows/` خط لوله داده از بسته قبلی
